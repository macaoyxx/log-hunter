## 目标（为什么做）

日志排查的第一步永远是「故障爆发在哪个时段」，此前这步只能靠肉眼扫时间列。业界标配（Kibana Discover / Splunk / Grafana Loki 首屏核心）是时间直方图：命中结果按时间桶的分布图，一眼看出爆发时段，拖框缩小时间范围立即重查。本次为指挥舱补上时间维度分析能力。

## 范围（做了什么，清单）

- 时间分布直方图（结果区上方横条）：命中按时间桶的级别信号色堆叠条形，故障爆发一眼可见；峰值时刻自动标注；悬停出桶详情（时段/总量/各级计数）
- 拖框缩放时间范围：框选时段 → 时间胶囊出现在「缩小到」筛选链 → 立即重查；直方图重分布为窗口内更细粒度；胶囊 × /「清除时间」按钮复原
- 双击直方图跳转定位：结果表滚到该时刻之后最早一条并选中（含跨段翻页）
- 无级别文件自动退化：无级别行归中性灰段，全部无级别时整体退化单色总量条；无时间戳行数单独提示
- 性能：桶聚合惰性计算不拖慢查询（2 亿行全览按文件并行），桶宽整刻度自适应（100ms~1d）
- 双主题（夜巡/日间）全走现有 token，所见即真实观感

## 影响面（没直接改但被牵连的）

- 无破坏性变更；`GetResults`/导出等现有链路不动
- `ResultRow.TS` 语义不变（仍存原始时间戳，锚点继承仅在直方图聚合/定位内部计算）
- 锚点继承语义新增两处同源实现（直方图聚合、IndexByTime），与 filterCandidates/sortMerged 四处必须同步改（已记 `.memory/anchor-inheritance.md`）
