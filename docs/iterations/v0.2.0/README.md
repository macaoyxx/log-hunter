## 目标（为什么做）

日志排查的第一步永远是「故障爆发在哪个时段」，此前这步只能靠肉眼扫时间列。业界标配（Kibana Discover / Splunk / Grafana Loki 首屏核心）是时间直方图：命中结果按时间桶的分布图，一眼看出爆发时段，拖框缩小时间范围立即重查。本次为指挥舱补上时间维度分析能力。

## 范围（做了什么，清单）

- 引擎：`internal/logscan/histogram.go`——直方图桶聚合（整刻度桶宽、按文件并行），三种结果形态（查询物化 / 零物化全览 / 全览物化）统一取数，无时间行按锚点继承语义归桶（与 filterCandidates/sortMerged 同一规则），无级别行归独立「未知」段；`IndexByTime` 双击跳转定位（零物化按文件二分+窗口校正，物化单遍锚点口径）
- 绑定：`app.go` 新增 `GetTimeHistogram`（60 桶起，桶宽整刻度自适应）与 `GetIndexByTime`（跳转定位）
- 前端：新组件 `TimeHistogram.vue`——结果区上方横条（Kibana 同款位置）：
  - 级别信号色堆叠条形（TRACE 底 → FATAL 顶，无级别行为中性灰段；全部文件无级别时整体退化为单色总量条）
  - 悬停桶详情浮层（时段 + 总量 + 各级计数）；峰值时刻自动标注
  - 拖框缩放时间范围：accent 蒙层选区 → 时间胶囊出现在「缩小到」筛选链 → 立即重查；点胶囊 × / 「清除时间」按钮即复原
  - 双击直方图 = 跳转定位：结果表滚到该时刻之后最早一条并选中（ResultTable 暴露 jumpToIndex）
  - 双主题（夜巡/日间）全走 style.css token
- 设计预览先行（已确认）：位置 A1 结果区上方横条；着色级别堆叠；无级别退化形态 D
