## 目标（为什么做）
v0.1.0 设置弹层一级菜单存在两个问题：① 菜单项文字被全局 button 的 `justify-content:center` 顶成居中（flex 布局下 text-align:left 无效）；② 纯文字列表信息密度低，「检查更新」缺版本上下文。经三版可视化对比（极简列表/图标+徽标/分组卡片）选定 B 版「图标槽行」。

## 范围（做了什么，清单）
- 设置一级菜单改为图标槽行样式：每项 28px 图标底槽（hover 点亮 accent）+ 主标题/副说明两行 + 右侧元素（主题项右箭头、检查更新项当前版本徽标、检查中反馈态）
- 修复菜单项居中 bug（显式 `justify-content:flex-start` 覆盖全局 button 规则）
- 二级主题面板（外观三态+主题色五套）结构不变，视觉随弹层宽度对齐

## 影响面
仅 ThemePopover.vue 一级菜单模板/样式与 App.vue 菜单插槽内容；主题切换/持久化/二级导航逻辑不动。
