## 目标（为什么做）
用户实测两处图标问题：①标题栏应用图标锯齿严重不丝滑——根因是 ICO 只嵌单张 256 大图，Windows 取 16/32px 时被系统低质缩放；②头部品牌栏的 ▮ 字符方块观感差，不需要。

## 范围（做了什么，清单）
- **genicon 多档渲染**：ICO 内嵌 7 档尺寸（16/24/32/48/64/128/256）每档独立 SDF 原生渲染（各档 8x 超采样抗锯齿，≤64px 档自动加粗笔画防细线碎裂）——系统按场景直取对应层、零缩放；256 档几何与原设计一致（appicon.png 无变化）
- **头部 ▮ 符号移除**：品牌栏直接以「LogHunter」文字开头

## 影响面
无接口与数据变化；注意 Windows 图标缓存——桌面/任务栏旧图残留需重建快捷方式或重启资源管理器（工作区指南已载）。

## 结果
- 新图标经视觉模型核验：边缘平滑、圆环线条均匀、渲染丝滑
- 发版：合并 main 后打 tag v0.0.8 发布（zip + sha256）
