## 目标（为什么做）
用户真实首测自动更新即失败：更新临时目录在系统盘（%TEMP%），exe 安装在其他盘（D:\tools\log-hunter），`os.Rename` 跨磁盘卷直接报错 `The system cannot move the file to a different disk drive`，新版落位失败（回滚保护生效，旧版无损）。v0.0.5/0.0.6 用户装非系统盘即卡死在断头路，必须热发修复。

## 范围（做了什么，清单）
- **跨盘落位降级**：落位优先同盘原子 rename，失败（跨卷）降级为复制到 exe 同盘 `.new` 临时名 → 同盘原子改名——任意盘安装可用；复制后 Sync 落盘保完整性；失败仍走回滚保持旧版可启动
- 新增用例：copyFile 内容一致性、落位源缺失回滚

## 影响面
仅 `internal/update` 落位逻辑，下载/校验/清理链路不变。

## 结果
- go test 三包全绿；wails build 通过
- 发版：合并 main 后打 tag v0.0.7 发布（zip + sha256）
- 验证：v0.0.6（D 盘安装）检查更新 → 自动更新到 v0.0.7 全链路
