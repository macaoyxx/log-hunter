## 目标（为什么做）

v0.3.0 上线后的版后热修：设置页出现 "undefined" 字样与手填模型预填 0 的显示混淆；全项目扫描发现默认值/超时类字面量散落多处，是「改一漏一」的温床。

## 范围（做了什么，清单）

- 设置页全局默认为空（打开早于配置拉取/拉取静默失败）时占位符拼出 "undefined"——cloneConf 与占位符双层兜底
- 手填模型不预填 ctx/maxOut 的 0：留空时占位符展示全局默认，「空=用默认」在 UI 如实可见；保存链经后端零值回落语义闭环
- 默认窗口/响应/贴图上限收敛到 frontend/src/constants.ts 唯一事实源（AI_DEF_CTX/AI_DEF_MAXOUT/AI_IMG_MAX_BYTES），跨语言镜像对注释标注两头同步勿漂移
- 后端 roundTimeout（诊断/追问）与 pullTestTimeout（拉取/测试）常量化，各两处内联收敛
- AI 设置文件头注释与现状对齐

## 结果（上线状态、验证方式、遗留事项）

- 遗留：无
