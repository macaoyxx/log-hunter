## 目标（为什么做）

本地检索已贴 IO 物理极限（20GB 全扫 8-13s、时间类 ms 级、全览 0s），AI 不参与也不会加速检索；真缺口在定位之后——搜出几万条 ERROR 后「人读懂」的几十分钟。本迭代补两块能力：

1. **本地错误聚类**（无 AI、确定性）：行模板归一 + 指纹分组，一眼回答「错误有几种、各多少条、代表行长什么样」
2. **内置日志分析专家（自主 Agent，opt-in）**：聚类结果压缩为带行号锚点的上下文，发 OpenAI 兼容端点；AI 调用只读工具自主取证（function calling 循环）、受控产出文档；多轮追问、贴图（视觉路由/中转）。核心纪律：分析必须有依据有证据、不瞎编——引用可校验、取证过程可见、视觉转述可核对

## 范围（做了什么，清单）

- 本地错误聚类：当前结果集模板归一分组（时间戳/数字/GUID/IP → 占位符），组列表（模板/计数/级别/时间范围/占比），点组/样本行跳转联动；>10 万行均匀采样并标注口径
- 内置日志分析专家 Agent：专家 system prompt 内置（概览→根因假设按置信度排序（支持/反对证据）→证据链时间线→影响范围→建议操作，【事实】【推断】【待验证】三态标注）
- 自主取证工具（只读影子路径，不破坏用户结果集）：search / get_context / get_line / histogram / cluster
- 受控产出：write_doc 落本次会话报告目录（文件名清洗防穿越），产出文档卡片打开/另存
- 双口径引用 + 前端校验：[行 N] 跳结果表、[文件名:行号] 开上下文面板，越界引用标红——编造引用一眼可辨
- 多厂商档案 + 会话内切模型：N 个端点档案（名称/BaseURL/APIKey/模型列表），主/视觉档案独立选择（跨厂商组合）；会话顶栏随时切模型续聊
- 模型能力配置：模型级 ctx（窗口）/ vision（视觉）/ maxOut（响应上限），内置常见模型能力表预填；贴图按 vision 自动路由（直发 or 视觉中转）
- 贴图与视觉中转：主模型多模态直发；纯文本模型走视觉档案转述（只忠实提取、看不清说看不清，转述可折叠核对——防瞎编三道闸）
- 追问会话：多轮延续、AI 查询建议一键执行、历史超预算截最早轮、结果集变化会话失效、随时取消
- 源码读取授权（human-in-the-loop）：AI 可请求读源码（read_source 工具）——授权卡三选项（允许并记住（持久 ai.json）/ 仅本次 / 拒绝），拒绝后本会话不再问；拖入文件/文件夹到输入框 = 路径附件（不读内容、不进左侧日志列表，AI 经授权自行读取，目录返回一层清单）
- 敏感文件逐次授权：yml/env/json/properties/密钥类文件（可能含凭证）不受目录授权覆盖——逐文件、每次读取单独授权（无记住选项，拒绝后本会话不再问）
- 思考等级会话中随切；Ctrl+V 粘贴截图；markdown 渲染补齐（表格/有序列表/引用/链接/分割线/代码块语言标注）
- OpenAI 兼容协议：/chat/completions（SSE 流式 + function calling）+ /models；Bearer 鉴权（key 空不发 header，兼容 Ollama）；effort/maxOut 空不发字段防不兼容 400
- 配置独立 data/ai.json（明文、tmp+rename 原子写、0600），不进 config.json
