## 目标（为什么做）
① 拖入的日志常打包 zip，此前 zip 会被格式探测兜底成乱码纯文本加载，无法查询；② 排障时在上下文详情里想临时给关键内容（订单号、错误码）上色归类，只能看不能标。

## 范围（做了什么，清单）
- **zip 自动解压**：AddFiles 按 .zip 分流 → 解压到会话临时目录（懒建 `%TEMP%\log-hunter-unzip-*`，每 zip 一子目录）→ 内容级二进制校验（前 16KB 含 NUL 判二进制跳过，不吃扩展名的亏，`.log.101` 等照收）→ 文本文件按 `zip名/相对路径` 显示名入会话；嵌套 zip 不递归（天然被二进制校验跳过）；GBK 文件名解码、Zip Slip 防护、加密跳过、8GB 解压上限、进度 Phase="unzip"、ctx 取消；zip 源路径去重防双份内存；RemoveFile/ClearAll/退出自动清理临时目录
- **详情右键格式标记**：详情面板内选中文本右键弹自绘菜单（无选中也弹，禁用态控制）——复制选中 / 5 色槽位格式标记（标记1~5）/ 按使用中槽位清除 / 清除全部；标记后详情内所有相同文本同步着色；面板打开期间保留（jump/调行数不丢），关闭面板清空；后按用户反馈重设计为**二级级联子菜单**（主菜单「复制/加标记▸/清除标记▸」，子菜单通道色条项，悬停预览色，视口溢出翻转）
- **无条件浏览全部**：查询条件留空 = 浏览全部行（索引惰性直出，预览延迟生成沿用）；首次加载自动全览（追加文件不自动）；多文件按拖入顺序拼接；筛选链锁放开（胶囊删光回全部）；placeholder/历史「(无条件)」配套
- **详情面板放大**：⛶ 按钮切换铺满全屏/还原（width 过渡动画），面板期间状态；上下文默认前后行数 30→100；时间列完整 `yyyy-MM-dd HH:mm:ss.SSS`，文件列收窄留空间给内容
- **昼夜主题 + 信号色板**：夜巡（默认）/日间双主题，默认自动跟随系统（matchMedia + localStorage 持久化 + 窗框 SystemDefault）；表面四级层级（页面/面板/组件/浮层）解决浮层与面板融为一体的"淡化"观感；信号色板两主题各自调校（级别色提对比、标记色、灰层文字提亮）；右键菜单禁用态可读、无选中仍可展开子菜单；组件约 27 处硬编码色收编 token
- **拖拽修复与添加入口**：OnFileDrop 正规注册修复拖拽从未生效（v0.0.1 起链路未接通）并放开全窗口可放；有文件状态补「＋ 添加文件」按钮
- **删除文件结果联动**：删单个文件按最近条件自动重查剩余文件（无历史退回输入框条件），全删完等价清空重来；清空后 FreeOSMemory 立即归还内存
- 绑定层 AddFilesResult.Notices 跳过提示与 Errors 分离；PickFiles 过滤器 + *.zip
- 测试：zip 解压全场景单测（二进制跳过/GBK 名/ZipSlip/加密/清理）+ 无条件全览单测（单文件含无时间戳行/双文件拼接顺序）
