## 目标（为什么做）

v0.3.2 版后用户实测直方图暴露三处缺陷：窗口缩放图不跟随重绘、悬停详情浮层上下被裁且不跟随鼠标、双击跳转落点错乱（点 01:45 跳到 04:30 / 日志少不跳 / 末桶不跳）。

## 范围（做了什么，清单）

- **双击跳转根因修复**：IndexByTime 零物化分支的 sort.Search 被无时间堆栈行（ts=0）欺骗——0 使判定恒 false、二分整段右跳，跳过段后真实命中行。改为 searchEffective 有效值二分（非零单调 + 0 继承锚点 = 有效值单调，mid 为 0 取锚点判定），O(log n) 保持；大 0 段欺骗回归用例锚定；真实日志真机三点位复测（01:45→02:07:21、密集柱、末柱）全过
- **重绘修复**：ResizeObserver 改 watch 补挂——模板根 v-if 空态挂载时一次性 observe 被静默跳过，此后直方图出现也无人监听（svgW 停旧值：放大留白/缩小右裁）
- **悬停浮层重做**：fixed 视口定位（卡片 ~116px 矮于浮层 ~170px 且 overflow:hidden，absolute 上下必裁）+ 近视口顶自动翻到下方 + 横向钳制收口 onMove 单一坐标系（曾两套坐标系打架致右移不跟随）
- **双击取值改按桶**：桶起始边界替代像素比例插值（插值时刻常晚于行时间致静默不跳）
- 清理：「清除时间」按钮（筛选链时间胶囊已覆盖）与提示文字行
