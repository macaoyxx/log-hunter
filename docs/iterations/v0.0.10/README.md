## 目标（为什么做）
用户反馈旧配色「AI 味太浓」。诊断实锤三处通用默认：表面色全族蓝灰 slate（AI 暗色仪表盘默认底）、信号色整组照抄 GitHub Primer 原值（别家的默认）、琥珀强调色挂在蓝灰上无出处。换为有出处的「碳晶·磷光」体系——琥珀出自大型机时代的琥珀磷光单色终端（P3 荧光，最早的读日志仪器），日间出自工程师绿杠打印纸（浅绿条纹本为帮眼睛横穿宽行日志而生）。

## 范围（做了什么，清单）
- **夜巡主题重制**：蓝灰表面梯 → 暖石墨碳面四级（bg/panel/elev/float），投影改暖黑
- **日间主题重制**：GitHub 灰 → 微绿「绿杠纸」纸面 + 墨色文字 + 纸叠顶页浮层
- **级别 6 色重调**：DEBUG 改磷光青（弃通用 UI 蓝）、WARN 正黄与琥珀金拉色相、FATAL 改酒红玫瑰与 ERROR 暖红分离；标记 5 通道与关键字命中高亮随新体系重校
- **对比度保障**：两主题 56 项 pair 脚本核验全达标（主文字≥7:1、徽章≥4.5:1、日间琥珀≥5:1），三轮视觉模型核验收敛
- **token 纪律收口**：消灭组件内最后 6 处硬编码色值（2 遮罩 → 新增 --mask，4 处琥珀底深字 → --amber-ink）；33 个变量名零改动、组件结构零牵连

## 影响面
无——纯 token 值替换，变量名/组件结构/布局字体圆角均未动；标记槽位名（红/黄/绿/蓝/紫）与色相族仍一一对应。

## 结果
- 验证：`npm run build`（vue-tsc + vite）通过；对比度脚本 + 预览页三轮视觉核验通过
- v0.0.10 已发布（tag + GitHub Release，产物 zip + sha256）
