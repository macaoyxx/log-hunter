## 目标（为什么做）
用户实测反馈两个界面问题：①频繁点击「查一下」报 `context canceled` 错误——查询中按钮已切换为「停止」，快速连点实际点到的是停止，用户主动取消被当错误弹窗；②详情面板复制反馈显示在头部不直观，结果表右键缺少「复制选中文本」。

## 范围（做了什么，清单）
- **取消误报修复**：主动停止（后端 context.Canceled）静默归位不再弹错；加请求代次 guard，旧查询迟到的回调不误动新查询状态（停止后立刻重查不再按钮错乱）
- **复制菜单反馈统一**：详情面板「复制选中/复制本行」反馈改为菜单内「✓ 已复制」后收起（与结果表一致），头部只留「复制全部」
- **结果表右键新增「复制选中文本」**（无选中置灰，同样走后端直写剪贴板）
- 两处反馈定时器在重开菜单时先清理，防 700ms 窗口内误关新菜单

## 影响面
纯前端改动（App.vue / ContextMenu / ContextPanel / ResultTable），无接口与数据变化。

## 结果
- vue-tsc + wails build 通过；pr-review 97/100（能合），唯一 🟡（定时器竞态）已修
- 手测路径：频繁点击查询不报错；两处右键菜单 ✓ 反馈与收起；结果表选中文本右键复制
- 发版：合并 main 后由用户经 publish.sh 确认门打 tag v0.0.6 发布（zip + sha256）
